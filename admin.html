客户端连接指南
Windows：打开文件资源管理器 → 右键"此电脑" → 映射网络驱动器 → 输入服务器地址 → 勾选"使用其他凭据" → 输入用户名和密码
macOS：Finder → 前往 → 连接服务器（Cmd+K）→ 输入服务器地址 → 输入用户名和密码
iOS：使用"文件"App → 浏览 → 连接服务器 → 输入服务器地址和凭据
Android：使用支持 WebDAV 的文件管理器（如 Solid Explorer、ES文件浏览器）→ 添加 WebDAV 连接
跨平台：使用 RaiDrive、Cyberduck 或 WinSCP 等工具连接
