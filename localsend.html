连接不上？查看使用条件与排障指南
  1. 关闭接收设备的加密（重要）：LocalSend 默认使用带自签名证书的 HTTPS，浏览器不信任该证书。请在对方设备的 LocalSend 中打开 设置 → 网络 → 关闭「加密」（此时使用 HTTP 传输，指纹为随机串，仍在局域网内，安全影响可接受）。
  2. 通过 HTTP 访问本站：如果当前地址是 https://，浏览器会拦截页面发往局域网 http:// 地址的请求（混合内容限制）。请将本站部署在内网并通过 http://内网IP:端口 访问（例如本地运行 npm start），或在浏览器站点设置中允许「不安全内容」。
  3. 确认在同一局域网：设备地址通常是 192.168.x.x，端口默认 53317。可在 LocalSend 应用「接收」页或「设置 → 网络」中查看本机 IP 与端口。
  4. 浏览器无法被「发现」：浏览器不能监听端口、也不能收发组播包，所以本页只能主动连接设备，不会出现在对方设备列表里。设备互传请双方都用 LocalSend，浏览器互传请用快传。
  5. PIN 保护：若对方开启了 PIN，发送时按提示输入即可。
  6. 云端部署的限制：部署在 Cloudflare 等公网时，服务器中继无法触达您的内网设备，页面将只能直连（受浏览器限制较多）。内网自托管时中继可用，体验最佳。
