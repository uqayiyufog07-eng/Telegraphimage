**LocalSend 实现要点（关键技术结论）**
- LocalSend 服务端**无 CORS 头、不处理 OPTIONS**（已核实源码），浏览器 fetch 直连无法读响应
- 浏览器不能监听端口/组播 → 网页只能主动连接设备，不会被"发现"
- LocalSend 默认 HTTPS 自签名证书 → 用户需在 App 设置→网络中关闭加密（HTTP 模式）
- HTTPS 页面访问 http://内网IP 被浏览器混合内容拦截 → 建议内网 HTTP 访问本站
- 解决方案：新增 `/api/lan/relay`（functions/api/lan/relay.js）同源中继，仅允许私有网段（10/8、172.16/12、192.168/16、127/8、localhost、*.local），禁 169.254/16 与凭据 URL；云端部署时中继不可达内网，前端自动降级并提示用"快传"
- 协议流程：info 探测（direct→relay 双通道）→ register → prepare-upload（401 弹 PIN）→ upload（XHR 带进度）→ cancel；接收走 prepare-download + relayBlob 下载
